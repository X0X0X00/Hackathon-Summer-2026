# WYH — MERFISH Cell-Type Annotation

Team-delivery branch for the University of Rochester Biomedical Data Science
Hackathon Summer 2026. WYH contributed a leakage-safe modeling track based on
external-reference transfer, frozen fold protocols, and evidence-based model
selection.

## Modeling Summary

The selected WYH research model is **MODEL V2** (V2-B-REFONLY): a reference-only
LightGBM classifier fit on a cleaned public MERFISH spinal-cord reference and
evaluated under the team-compatible five-fold protocol.

- Validation accuracy: **82.12%** (4106 / 5000)
- External reference cells used: **136,574**
- Improvement over MODEL V1: **+6.14 percentage points**
- Later V3 experiments did **not** replace MODEL V2. The strongest V3 candidate
  (E06M M2, 82.18%) gained only three net cells and was not stable enough to
  promote.

MODEL V2 is a research/selection candidate, **not** the file currently scored
from this branch. It was recorded as **Not submitted** to official scoring.
Its candidate artifact is
[`work/experiments/evidence/submissions/model_v2_candidate.csv`](work/experiments/evidence/submissions/model_v2_candidate.csv).
That candidate is **not identical** to [`prediction/prediction.csv`](prediction/prediction.csv).
This cleanup does not change either file.

## Reproduction

```bash
python3 -m venv work/.venv
work/.venv/bin/pip install -r work/requirements.txt
work/.venv/bin/python work/scripts/00_validate_data.py
work/.venv/bin/python work/scripts/10_official_manifest.py --verify
work/.venv/bin/python work/scripts/90_validate_submission.py prediction/prediction.csv
work/.venv/bin/python -m pytest -q work/tests
```

To reconstruct MODEL V2 (does not write `prediction/prediction.csv`):

```bash
# place the approved Zenodo file first; see External data
work/.venv/bin/python work/scripts/09_v2b_refonly.py
```

## External data

MODEL V2 requires the approved Zenodo MERFISH spinal-cord deposit:

- filename: `MERFISH_spinal_cord_resolved_0718.h5ad`
- local path: `work/external/MERFISH_spinal_cord_resolved_0718.h5ad`
- expected MD5: `ce06f62c0ec4973581dae17bb76f0cd9`
- source recorded in this repository: Zenodo record **18039571** (Wang … Meltzer, same MERFISH spinal-cord study)

Place that file at the local path above and verify the MD5 before running
`work/scripts/09_v2b_refonly.py`. The raw `.h5ad` is local-only and must not be
committed. This repository does not record a download URL. See
[`work/docs/versions/model_v2.md`](work/docs/versions/model_v2.md).
